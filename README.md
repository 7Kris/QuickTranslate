# QuickTranslate

macOS メニューバー常駐型の翻訳アプリ。グローバルショートカットキーでクリップボードのテキストを即座に翻訳します。

## 機能

- **グローバルショートカット** (Command+Shift+T) でどこからでも翻訳を呼び出し
- **クリップボード連携** — ショートカットを押すとクリップボードのテキストを自動取得
- **自動言語判定** — 英語→日本語、日本語→英語を自動で判定して翻訳
- **フローティングウィンドウ** — 最前面に翻訳結果を表示
- **コピーボタン** — 翻訳結果をワンクリックでコピー
- **メニューバーアプリ** — Dockに表示されず、メニューバーに常駐

## 技術スタック

- Swift / SwiftUI
- macOS 26 以降 (Apple Translation API 利用のため)
- Swift Package Manager

## セットアップ

### 1. ビルド

```bash
swift build
```

### 2. 翻訳言語パックのダウンロード

Apple Translation はオンデバイス翻訳のため言語パックを事前にダウンロードする必要があります。

`システム設定 > 一般 > 言語と地域 > 翻訳言語` から日本語と英語をダウンロードしてください。

### 3. 実行

```bash
swift run QuickTranslate
```

または `.build/debug/QuickTranslate` を直接実行してください。

### 4. アクセシビリティ権限

初回起動時、macOS の「システム設定 > プライバシーとセキュリティ > アクセシビリティ」でアプリへの許可が必要な場合があります。

## 使い方

1. アプリを起動するとメニューバーにアイコンが表示されます
2. 翻訳したいテキストをコピー (Command+C)
3. Command+Shift+T を押す
4. フローティングウィンドウに翻訳結果が表示されます
5. 「コピー」ボタンで翻訳結果をクリップボードにコピーできます
